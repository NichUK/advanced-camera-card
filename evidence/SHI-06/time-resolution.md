# Explicit recording time and interval resolution

Date: 2026-10-05. Ordered implementation checkpoint; dependencies and current-head review remain open.

The HA archive camera now publishes its configured IANA site timezone. Shinobi's rendered date input uses that zone; older adapters fall back to HA's configured timezone. In mixed site-zone views it uses the labelled HA zone. The visible controls label recording-input timezone and browser timeline-axis timezone separately. Other engines retain their existing date input behavior.

Local input is resolved by enumerating offsets around the selected day and round-tripping each candidate. Paris's nonexistent spring-forward hour is rejected with an explanation. The repeated autumn hour requires an explicit UTC+02:00 or UTC+01:00 selection; there is no automatic fold choice. UTC clip identities and seeks do not depend on the developer/browser zone.

Intervals are half-open. An exact contiguous boundary selects the next clip at offset zero. Midnight-spanning files retain offsets from their actual start. Overlaps use ACC's longest-covering-file preference; equal durations are ordered by start time, then opaque ID lexicographically, so upstream response order cannot change the selection. Invalid metadata fails discovery; an upstream empty SQL response is explicitly unverified, never a certified gap. A complete interval containing other valid clips can show an explicit gap at the selected instant without playing another time.

Unit checks cover Paris/London/New York/UTC equivalence, half-hour offsets and rollback, invalid dates/zones, nonexistent/repeated hours, contiguous boundaries, midnight and overlap ordering. Browser checks exercise the actual labelled input, offset selector and gap notification alongside decoded synthetic 4K playback. See SHI-05 for the original synthetic codec fixture and original Clear/iPhone limits. No recording, retention or production service configuration is changed. Final validation: 7,448 unit tests in 438 files pass with required 100% statements, branches, functions and lines. All 195 browser tests in 28 files pass, including the three rendered timezone/DST cases and actual synthetic playback. TypeScript, lint, production build and stylesheet compatibility checks pass. Exact playback is preserved across programmatic fitting and stale lifecycle callbacks; the date input stays usable during pending discovery. The companion adapter passes 62 isolated HA runtime tests.
